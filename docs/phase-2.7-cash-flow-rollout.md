# Phase 2.7 cash-flow rollout

1. Stage the additive cash-flow schema and operator tooling before enabling the full application release, or plan a pause in ordinary posting during review. Existing chart accounts remain `cash_role = NULL` (unreviewed); no role is inferred or assigned by migration. MySQL trigger creation may require temporary DBA preparation for error 1419, including `log_bin_trust_function_creators` where applicable.
2. Review every relevant existing chart account for each owner. Use the operator readiness listing to identify unresolved accounts, then assign each role explicitly with the cash-role review command. Review non-cash accounts as `non_cash`; do not infer roles from account names, codes, or types.
3. For historical posted ordinary cash journals needed through the reporting horizon, prepare explicit debit-to-credit allocations in a local JSON file. Each row has integer `debit_line_id` and `credit_line_id`, exact string `amount`, and `category` (`operating`, `investing`, `financing`, or `null` for cash-to-cash). Seal one journal at a time with the historical completion command. Opening-balance and fiscal-close journals are excluded.
4. Repeat the read-only readiness listing through the intended report end date until all relevant account roles are reviewed and required historical journals are sealed. The listing can omit cash journals while roles remain unresolved. An unsealed historical ordinary reversal is listed as unsupported for manual completion; investigate that history before reporting.
5. Release and use normal posting with reviewed roles. The full Phase 2.7 application enforces role review immediately when released; normal posting requires every referenced role to be reviewed and cash journal allocations to be complete. Unreviewed existing accounts block new ordinary postings involving them.
6. Validate the Statement of Cash Flows and its beginning plus adjustments plus activity equals ending reconciliation. The Cash Flow report can return a safe 409 until review and completion are ready.
7. Perform the full production smoke review. General Ledger, Trial Balance, Income Statement, and Statement of Financial Position remain usable during cash-role review.
